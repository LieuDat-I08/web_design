# Web Design

This repository contains my Web Design course exercises and practice projects.

## Technologies

- **HTML5**: Web page structure and content.
- **CSS3**: Styling and layout.
- **JavaScript**: Basic programming and interactive web features.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open any `.html` file.
4. Run the file using your browser or the Live Server extension.

## Purpose

- Practice HTML, CSS, and JavaScript.
- Complete Web Design course exercises.
- Build a foundation for front-end web development.
